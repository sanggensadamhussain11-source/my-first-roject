# Sangin Restaurant

A small, responsive restaurant website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No package installation or build step is needed. An internet connection is required to load the restaurant and food photos.

## Files

- `index.html` contains the page structure and restaurant content.
- `styles.css` contains the responsive layout and visual design.
- `script.js` adds menu filters and the reservation request interaction.
- `logo.svg` is the Sangin Restaurant wordmark and browser icon.

The menu photos are served by Unsplash. The reservation form shows an on-page request summary; it does not send bookings to a server.
